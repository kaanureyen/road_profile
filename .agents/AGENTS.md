# Project Rules

## Code Implementation Guidelines
* **Progress Logging**: All implemented code (scripts, simulations, test suites) must output clear progress logs to the console. This ensures execution status can be tracked dynamically.
* **Documentation & Reproducibility**: All project documentation and reports must be kept up to date. All test reports must be fully reproducible using their corresponding test scripts.
* **Visual Test Reports**: Every test suite must have its own directory containing a `README.md` report that explains the test, displays the results, and embeds corresponding visualization plots. This allows repository visitors to inspect every test and its outcomes directly on GitHub without cloning the repository.
